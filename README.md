# AI 侧边栏助手（AISA）

一款 Chrome / Edge（Chromium 内核，Manifest V3）浏览器扩展。核心解决两个痛点：

1. **切换 AI 麻烦** —— 在浏览器侧边栏（`chrome.sidePanel`）通过 iframe 直接嵌入 ChatGPT / Claude / Gemini 等真实网页端，登录态复用浏览器 cookie，无需来回切标签页。
2. **禁止复制 + 引用麻烦** —— 在任意网页（含禁止复制站点，如百度文库、CSDN、公众号）选中文字即可：自动复制到剪贴板、在侧边栏顶部高亮引用、一键粘贴进 AI 输入框。

## 功能一览

| 功能 | 说明 |
|------|------|
| 🤖 **侧边栏 AI 网页端** | 一键切换 ChatGPT/Claude/Gemini/DeepSeek/通义/Kimi/智谱/文心，iframe 嵌入真实网页（扩展自动移除反嵌入头） |
| 🗂 **分标签独立侧边栏** | 每个标签页拥有独立的 sidePanel 实例，各自记住自己的 AI 站点，**切标签不重载、状态各自保留** |
| 💬 **`@` 引用器（agent 式）** | 侧边栏顶部提示词组装区，输入 `@` 弹出候选：已选引用 / 当前选中 / 页面正文 / 其他标签页 / 剪贴板历史，组装后一键复制 |
| 📌 **选中引用（可编辑）** | 选中文字 → 浮动按钮「发到侧边栏」或「加到组装」；顶部引用条可直接编辑，`@` 引用取最新内容 |
| 🔓 **超级复制** | 破解禁止复制/右键/选择/粘贴，全局开关 + 站点级覆盖 |
| ⚡ **自动复制** | 选中即复制，支持纯文本 / Markdown 格式 |
| 📋 **剪贴板历史** | 本地存储所有复制内容，可搜索 / 重用 / 清空 |
| 🏷 **标签页复制** | 一键复制当前或全部标签页（标题/URL/Markdown/HTML/JSON/CSV 等多格式） |
| 🎈 **页面悬浮入口** | 每个网页右上角悬浮图标，点击直接打开侧边栏（可拖动/可关闭） |
| 📂 **顶部收纳** | 引用 + 组装区可一键折叠，专注看 AI 输出；收到新引用时自动展开 |
| ⌨️ **快捷键** | Alt+1 当前标签、Alt+2 全部标签、Alt+3 切换自动复制、Alt+4 历史 |

## 如何加载（开发者模式）

1. 打开 Chrome / Edge：地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）。
2. 右上角打开 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本目录 `quicksearch/`（即包含 `manifest.json` 的文件夹）。
5. 扩展加载后，点击工具栏的 🤖 图标 → 侧边栏打开。
6. 首次使用某 AI 站点前，建议先在普通标签页登录过该站点，侧边栏 iframe 才能复用登录态。

> Chrome 要求 ≥ 114（支持 `sidePanel` API）。

## 使用方法

### 1. 侧边栏调用 AI
- 点击工具栏 🤖 图标，或网页右上角的悬浮入口图标 → 侧边栏出现。
- 顶部圆角按钮切换不同 AI 站点，**每个标签页各自记住自己的选择**。

### 1.1 分标签独立侧边栏
- 每个标签页拥有**独立的 sidePanel 实例**：标签 A 选 Gemini、标签 B 选 Claude，互不干扰。
- 切换标签时侧边栏**不重载**，各自的 AI 网页状态原样保留（对话进度、滚动位置都在）。
- 新标签首次打开侧边栏时会加载一次该标签记忆的 AI（之后切走再切回不再重载）。

### 2. 选中文字 → 发到 AI
- 在任意网页选中一段文字，会浮现两个按钮：
  - **📌 发到侧边栏** —— 内容进入顶部「已选中的引用」条（可继续编辑）。
  - **➕ 加到组装** —— 直接作为芯片插入下方的提示词组装区。
- 即使侧边栏顶部已折叠，收到引用时会**自动展开**。
- 在侧边栏的 AI 输入框点一下，按 **Ctrl+V** 粘贴即可。

> 为什么是 Ctrl+V 而不是全自动？ChatGPT/Claude/Gemini 是**跨域** iframe，浏览器安全策略禁止扩展用 JS 直接写入它们的输入框。所以流程优化为「自动复制 + 视觉引导 + 一次粘贴」，适配所有站点且最稳定。

### 2.5 `@` 引用器（agent 式提示词组装）
侧边栏顶部「💬 提示词组装」区，支持组合多段上下文：

1. 在编辑框里输入你的问题，需要引用时打 **`@`**，弹出候选：
   - **✂️ 当前选中** —— 当前网页选中的文字
   - **📄 当前页面正文** —— 自动提取页面正文（去导航/广告，保留段落）
   - **🗂 其他标签页…** —— 展开当前窗口所有标签页，选其一引用其正文摘要
   - **📋 剪贴板历史…** —— 展开最近的剪贴板历史，选其一引用（历史作为现成的素材库，可直接搜正文内容筛选）
2. 选中候选后插入**引用芯片**（蓝色圆角标签），可继续叠加多个。
3. 点「📋 组装并复制」→ 芯片自动展开为引用块（含标题/来源 URL）+ 你的问题 → 复制到剪贴板。
4. 到 AI 输入框按 Ctrl+V 粘贴。

快捷按钮：「＋选中」「＋页面」可一键追加引用，无需手动打 `@`。

> **剪贴板历史**特别适合跨页面引用：之前在 A 站复制的内容、昨天查的资料，不用切回去重新复制，直接 `@` 从历史里挑。

> 最终粘贴的 Ctrl+V 同样受跨域 iframe 限制，无法消除；但 `@` 引用让"多源上下文组合"体验接近真正的 agent。

### 3. 破解禁止复制（超级复制）
- 点击 🤖 图标 → 弹窗里打开 **「超级复制」** 开关（全局）。
- 对特定站点单独设置：弹窗底部「站点独立设置」按钮，循环切换 跟随全局 → 强制开 → 强制关。
- 也可在「设置 → 站点级超级复制」用文本批量配置（每行 `+域名` 或 `-域名`）。

### 4. 剪贴板历史
- 弹窗点「🗂 剪贴板历史」，或按 **Alt+4**。
- 支持搜索、单条复制、单条删除、清空全部。

### 5. 标签页复制
- 弹窗点「📋 复制当前标签」/「📑 复制全部标签」，或快捷键 **Alt+1/Alt+2**。
- 复制格式在「设置 → 默认标签页复制格式」选择。

## 数据与隐私

- **所有数据仅本地存储**（`chrome.storage.local` / `sync`），不上传任何外部服务器。
- 破解复制功能默认关闭，需用户主动开启。
- 仅请求实现功能所需的最小权限。

## 已知限制 / 排错

- **某 AI 站点嵌入后白屏或异常**：少数站点除响应头外还有 JS 层 iframe 检测。侧边栏底部「⤢ 新窗口」可改为独立窗口打开兜底。
- **自动复制偶尔失效**：浏览器要求页面处于焦点才允许写剪贴板；扩展已降级到 `execCommand` 兜底。
- **快捷键冲突**：若 Alt+1~4 被占用，在 `chrome://extensions/shortcuts` 重新分配。
- **首次加载某 AI 站点需先登录**：iframe 复用浏览器 cookie，未登录会看到登录页。
- **首次切到某标签的侧边栏**：该标签的 sidePanel 实例是第一次创建，AI 网页需加载一次；之后切走再切回不再重载。
- **iframe 内自行切换对话不被记忆**：跨域 iframe 内的导航扩展无法感知，记忆的是通过侧边栏站点 tab 切换的状态。
