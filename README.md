# AI 侧边栏助手（AISA）

一款 Chrome / Edge（Chromium 内核，Manifest V3）浏览器扩展。核心解决两个痛点：

1. **切换 AI 麻烦** —— 在浏览器侧边栏（`chrome.sidePanel`）通过 iframe 直接嵌入 ChatGPT / Claude / Gemini 等真实网页端，登录态复用浏览器 cookie，无需来回切标签页。
2. **禁止复制 + 引用麻烦** —— 在任意网页（含禁止复制站点，如百度文库、CSDN、公众号）选中文字即可：自动复制到剪贴板、在侧边栏顶部高亮引用、一键粘贴进 AI 输入框。

## 如何加载（开发者模式）

1. 打开 Chrome / Edge：地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）。
2. 右上角打开 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本目录 `quicksearch/`（即包含 `manifest.json` 的文件夹）。
5. 扩展加载后，点击工具栏的 🤖 图标 → 侧边栏打开。
6. 首次使用某 AI 站点前，建议先在普通标签页登录过该站点，侧边栏 iframe 才能复用登录态。

> Chrome 要求 ≥ 114（支持 `sidePanel` API）。

## 使用方法

### 1. 侧边栏调用 AI
- 点击工具栏 🤖 图标，或网页右上角的悬浮入口图标 → 侧边栏出现。
- 顶部圆角按钮切换不同 AI 站点，**每个标签页各自记住自己的选择**。

### 1.1 全局常驻侧边栏 + 分标签独立记忆
- 侧边栏采用**全局常驻模式**：一旦打开，无论你如何新建标签页或在不同标签页之间切换，侧边栏都稳若泰山，**你在输入框内写到一半的内容绝对不会丢失**。
- **新建标签页防扰**：新建的空标签页默认不会强制弹出侧边栏，避免干扰。
- **网址模型独立记忆**：虽然侧边栏全局常驻，但它会根据你当前所在的标签页，**智能切换顶部选中的 AI 站点**。标签 A 选 Gemini、标签 B 选 Claude，切换标签时侧边栏无缝衔接。

### 2. 选中文字 → 发到 AI
- 在任意网页选中一段文字，会浮现两个按钮：
  - **📌 发到侧边栏** —— 内容进入顶部「已选中的引用」条（可继续编辑）。
  - **➕ 加到组装** —— 直接作为芯片插入下方的提示词组装区。
- 即使侧边栏顶部已折叠，收到引用时会**自动展开**。
- 在侧边栏的 AI 输入框点一下，按 **Ctrl+V** 粘贴即可。

> 为什么是 Ctrl+V 而不是全自动？ChatGPT/Claude/Gemini 是**跨域** iframe，浏览器安全策略禁止扩展用 JS 直接写入它们的输入框。所以流程优化为「自动复制 + 视觉引导 + 一次粘贴」，适配所有站点且最稳定。

### 2.5 `@` 引用与 `/` 自定义模板（Agent 式工作台）
侧边栏顶部「💬 提示词组装」区，支持高度自由的模块化组合：

1. **`@` 呼出上下文引用**：输入 `@` 弹出候选：
   - **✂️ 当前选中** / **📄 页面正文** / **🗂 其他标签页** / **📋 剪贴板历史**。
   - 插入后生成蓝色**引用芯片**。
2. **`/` 呼出提示词模板**：输入 `/` 弹出自定义模板：
   - 支持预设模板（如 `/fy` 翻译、`/zj` 总结等）。
   - 插入后生成紫色**提示词芯片**。
3. **沉浸式内联存为模板**：在输入框写好绝妙的提示词后，点击 **「➕ 存为模板」**，直接在当前侧边栏弹出一个精美的悬浮卡片，无需跳转设置页即可一键保存为新模板。
4. **芯片化排版**：芯片让杂乱的长文本在输入框内保持整洁。点击「📋 组装并复制」后，自动将所有芯片连同你输入的文本组装成完整的 Markdown 格式。
5. 到 AI 输入框按 Ctrl+V 粘贴。

快捷按钮：「＋选中」「＋页面」可一键追加引用，无需手动打 `@`。

> 最终粘贴的 Ctrl+V 同样受跨域 iframe 限制，无法消除；但 `@` 和 `/` 的组合让"多源上下文组合"体验接近真正的 agent。

### 3. 破解禁止复制（超级复制）
- 点击 🤖 图标 → 弹窗里打开 **「超级复制」** 开关（全局）。
- 对特定站点单独设置：弹窗底部「站点独立设置」按钮，循环切换 跟随全局 → 强制开 → 强制关。
- 也可在「设置 → 站点级超级复制」用文本批量配置（每行 `+域名` 或 `-域名`）。

### 4. 剪贴板历史
- 弹窗点「🗂 剪贴板历史」，或按 **Alt+4**。
- 支持搜索、单条复制、单条删除、清空全部。

### 5. 标签页复制
- 弹窗点「📋 复制当前标签」/「📑 复制全部标签」，或快捷键 **Alt+1**（当前标签）。「复制全部标签」仅在弹窗中提供。
- 复制格式在「设置 → 默认标签页复制格式」选择。

### 6. 数据备份与迁移（防止重装/换电脑丢数据）
- **设置 → 数据备份**：
  - **导出备份**：把当前所有数据（设置、提示词、剪贴板历史、站点列表）打包成一个 JSON 文件，存到本地任意位置。
  - **导入备份**：选中之前导出的 JSON，一键覆盖恢复。
- 扩展已通过 `manifest.json` 的 `key` 字段锁死扩展 ID（`jmcipihflnlfjgdchagpkpgijoopcabj`）。这意味着：
  - **重新加载 / 更新代码 / 换目录加载，扩展 ID 都不再变化**，`chrome.storage` 里的数据始终能被正确读取，不会"凭空丢失"。
  - 唯一仍会清空数据的情况是「在 chrome://extensions 里手动移除扩展」——这种情况请先导出备份。

## 数据与隐私

- **所有数据仅本地存储**（`chrome.storage.local` / `sync`），不上传任何外部服务器。
- 破解复制功能默认关闭，需用户主动开启。
- 仅请求实现功能所需的最小权限。

## 已知限制 / 排错

- **某 AI 站点嵌入后白屏或异常**：少数站点除响应头外还有 JS 层 iframe 检测。侧边栏底部「⤢ 新窗口」可改为独立窗口打开兜底。
- **自动复制偶尔失效**：浏览器要求页面处于焦点才允许写剪贴板；扩展已降级到 `execCommand` 兜底。
- **快捷键冲突**：若 Alt+Q / Alt+1/3/4 被占用，在 `chrome://extensions/shortcuts` 重新分配。
- **首次加载某 AI 站点需先登录**：iframe 复用浏览器 cookie，未登录会看到登录页。
- **首次切到某标签的侧边栏**：该标签的 sidePanel 实例是第一次创建，AI 网页需加载一次；之后切走再切回不再重载。
- **iframe 内自行切换对话不被记忆**：跨域 iframe 内的导航扩展无法感知，记忆的是通过侧边栏站点 tab 切换的状态。
- **手动「移除扩展」会清空数据**：扩展 ID 虽已固定（`key` 字段），但 `chrome.storage` 的生命周期与扩展绑定，移除扩展会一并删除。重装或换电脑前请先用「设置 → 数据备份」导出 JSON。
